# AirPen

VRChat のペンのように、空中に線を描けるプラグイン(Paper 1.21.11 / 前提: ProtocolLib)。

## 使い方

`/airpen give [プレイヤー]` でペンを渡す(権限 `airpen.admin`)。渡されたペンは権限なしで誰でも使える。

| 操作 | 動作 |
|:-----|:-----|
| 右クリック長押し | 描く(消しゴム ON のときは、視線の先のインクを消す) |
| 左クリック | ラジアルメニューを開く。開いている間は、見ている項目を左クリックで決定。真ん中(またはメニューの外)はキャンセル |

メニュー: 色 / 太さ / 消しゴム / 元に戻す / 全部消す / 他の人に見せる(初期値 OFF = 自分にだけ見える)。

- 色: 10 色のプリセットと、チャットで `#RRGGBB` を入力するカラーコード指定。
- 太さ: スライダー。左右を見て太さを選び、左クリックで決定(実寸のプレビュー付き、1〜30 の整数で表示)。

インクには上限があり、ペンの耐久値バーに残量が出る(`airpen.unlimited` を持つ人は無制限。admin は自動で付く)。
本人がログアウト・ワールド移動したとき、または線から 100 ブロック以上離れたとき、その人の線は消える。

## コマンド

| コマンド | 権限 | 内容 |
|:--|:--|:--|
| `/airpen give [player]` | `airpen.admin` | ペンを渡す |
| `/airpen clear` | 誰でも | 自分の線を消す |
| `/airpen clear <player\|all>` | `airpen.admin` | 他人の線、または全員の線を消す |
| `/airpen reload` | `airpen.admin` | 設定を再読み込み |
| `/airpen calibrate` | `airpen.admin` | 見ているブロックの面に 1×1 の確認用の板を出す(板の寸法の確認) |
| `/airpen cleanup` | `airpen.admin` | どの線にも属していないインク・古いメニューの表示を削除 |
| `/airpen inspect` | `airpen.admin` | 視線の先のインクが管理中か・迷子か・クライアントだけの表示かを調べる |
| `/airpen debug` | 誰でも | 入力状態の表示(アクションバー)とメニューの操作ログ(チャット)を切り替え |

## 仕組み

- **線**: 既定は、常にこちらを向く正方形の点(TextDisplay の背景)を並べる方式。設定で、平らな帯(ribbon)や
  細長いブロック(bar)にもできる。エンティティは保存されず(`persistent=false`)、再起動で消える。
  表示は所有者と、公開中なら他のプレイヤーにだけ。どの線にも属さなくなった表示は 30 秒ごとに自動で消す。
- **右クリック長押し**: ペンは 1 時間かかる無音の「使用」ができるアイテム(consumable)なので、押している間と
  離した瞬間がサーバーに届く。チェストなど「使用」が始まらない場所では、押している間 4 tick ごとに届く右クリックで判定する。
- **左クリック**: 押すたびに届く腕振りのパケットで判定する(Mob への攻撃は除く)。ブロックを掘る操作と、
  ブロック・エンティティへの右クリック操作は握りつぶすので、ペンで壊したり開けたりはできない。

## 設定

`config.yml` 参照(描き方、ペン先の距離、手ぶれ補正、インクの量、自動で消える距離、消しゴム、太さの範囲、色、メニューの距離など)。
