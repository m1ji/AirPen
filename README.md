## つかいかた！！

`/airpen give [プレイヤー]` でペンを渡す！！
渡されたペンは、権限なしで誰でも使える！！草むしり検定もいらない……ってコト！？

| 操作 | なにが起きる！？ |
|:--|:--|
| 右クリック長押し | 線を描く！！ウラ！！消しゴムが ON なら、見ているところのインクを消す！！ |
| 左クリック | メニューを開く！！見ている項目を左クリックで決定！！真ん中かメニューの外ならキャンセル……フ…… |

### メニュー！！

- **色** … 10色から選べる！！チャットに `#RRGGBB` と打てば好きな色にもできる！！ワ……ァ……！！
- **太さ** … スライダーで 1〜30！！実際の太さのプレビューが出る！！太い……！！細い……！！
- **描く位置** … 目からペン先までの距離を 0.5〜3.0 ブロックで変えられる！！
  赤い点のところに描ける！！下の目盛りで奥行きもわかる……ってコト！？！？
- **消しゴム** … ON/OFF！！ON の間は右クリック長押しで消す！！ゴシゴシ！！
- **元に戻す** … 最後に描いた線を消す！！なかったことに……なる……！！
- **全部消す** … 自分の線を全部消す！！ヤダーーーッ！！！(押したのは自分)
- **他の人に見せる** … 最初は OFF(自分にだけ見える)！！見せる勇気が出たら ON！！ハァ……ッ！！

色・太さ・描く位置を選んだあとのメニューも、最初と同じ場所に出る！！迷子にならない！！やったーーッ！！

### インク！！

インクには上限がある！！残りはペンの耐久値バーで見られる！！
なくなったら、消しゴム・元に戻す・全部消す のどれかで減らせば、また描ける！！なんとかなれーーーッ！！！
`airpen.unlimited` を持っている人はインク無限！！ズルい……！！ズルいよ……！！(admin には自動で付く)

### 線が消えるとき！！

次のどれかで、その人の線は消える！！イヤッ……！！……さみしいけど、仕方ない……！！

- ログアウトしたとき！！
- 別のワールドへ移動したとき！！
- 線の描き始めから 100 ブロック以上離れたとき！！遠いッ！！
- サーバーを再起動したとき(線は保存されない)！！ハァ！？

## コマンド！！

| コマンド | 権限 | 内容 |
|:--|:--|:--|
| `/airpen give [player]` | `airpen.admin` | ペンを渡す！！どうぞ！！ |
| `/airpen clear` | 誰でも | 自分の線を消す！！ |
| `/airpen clear <player\|all>` | `airpen.admin` | 他の人の線、または全員の線を消す！！ウラ！！ウラウラ！！ |
| `/airpen reload` | `airpen.admin` | 設定を読み直す！！ |
| `/airpen calibrate` | `airpen.admin` | 見ているブロックの面に、線の寸法を確かめるための 1×1 の板を出す！！ピッタリ……！？ |
| `/airpen cleanup` | `airpen.admin` | どの線にも属していない表示と、古いメニューを消す！！討伐ーーーッ！！ |
| `/airpen inspect` | `airpen.admin` | 見ている線がサーバーで管理されているか、迷子か、見た目だけ残ったものかを調べる！！調査……！！ |
| `/airpen debug` | 誰でも | 入力の状態(アクションバー)とメニューの操作ログ(チャット)を表示する！！ |

## しくみ！！

- **線** … 既定は、描いた人のほうを向く平らな帯(TextDisplay の背景)！！
  設定で、点を並べる方式(dots)や細長いブロック(bar)にも変えられる！！
- **見える人** … 描いた本人と、「他の人に見せる」が ON のときの他のプレイヤーだけ！！ナイショ……！！
- **右クリック長押し** … ペンは「食べる」ときと同じ仕組みで、押している間と離した瞬間がわかる！！
  音もアニメも出ない！！食べてない！！食べてないってば！！
- **ブロック** … ペンでブロックを壊したり、チェストを開けたりはできない！！ペンだから……！！
